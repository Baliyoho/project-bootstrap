# 目標與範圍

> 最後更新：2026-11-22
> v4 草稿，從需求決策書 v3 第 1 節拆出。回答「這個產品要達成什麼、給誰用、做到哪裡為止」。

## 目標

讓一個人用 Claude Code 與 Codex 兩個工具，在少數幾個專案上輪流工作時：下一棒不必問任何人就能從 origin 拿到最新成果、知道現況，不跟別人互相覆寫；沒驗證的事不冒充已驗證。

## 核心原則

制度只負責「模型不會自己知道的事」，不負責教模型怎麼做，也不自己造執行屏障。其餘條文都是這句話的推論。

## 範圍

- 兩個工具：Claude Code、Codex。兩個都是每月 20 美元的訂閱，用量有五小時與每週上限。
- 一個使用者、約十個以內的專案、每個專案通常一條線。
- 一次一個 session 是常態。不設計多 agent 並行編排；子代理只在使用者要求時用。
- 不支援 Antigravity 與 Gemini：不是驗收對象，目標部署形狀不含它們的接線與轉接檔。

## 分期

平台與作業系統分三期，前一期驗過才做下一期：

| 期 | 範圍 | 做完代表 |
|---|---|---|
| 1 | Claude Code＋macOS | **基本版完成** |
| 2 | Codex＋macOS | 兩個工具在 macOS 上等價（F14） |
| 3 | Claude Code 與 Codex＋Windows | 換作業系統不改變結果（F15） |
