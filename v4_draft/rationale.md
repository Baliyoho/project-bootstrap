## 非目標的理由

以下出自實施計畫 v3 第 5 節。

| 非目標 | 理由 |
|---|---|
| 不以永久的平台分支維護多份核心 | Git、占用、文件與同步的判斷要共用，平台差異放模組；兩份各自演化會出現一邊會擋、一邊不會擋的不對稱（出處：效率計畫 7.3、理由檔副本規則 2）〔計畫 §5〕 |
| 不恢復凍結的執行屏障與簽章發布通道 | D9 把執行屏障交給工具；十個以內的專案用不到金鑰鏈〔計畫 §5〕 |
| 不以自動信任 hook、繞過沙箱或搬運憑證換取速度 | D9 把權限與沙箱交給工具原生能力；hook 信任不能以快取代替當下觀測（出處：效率計畫 5.2）〔計畫 §5〕 |
| 不一次重寫所有程式、不先導入框架、不預先宣稱跨作業系統或 Python 下限通過 | 框架增加依賴與載入差異，本專案沒有量測支持（出處：效率計畫 14.7）；Python 下限只有靜態檢查；跨作業系統要等第 3 期（F15）〔計畫 §5〕 |
| F22 不另設時間上限 | F22 只照 D11 的行數預算〔計畫 §5〕 |
