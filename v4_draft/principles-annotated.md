| **3. 協作系統的設計原則** | | |

| 3. 每個事實只有一個家，其他地方只放連結，不重述。「讀得懂」指理解它所需的知識都有索引可循。每個連結都要說明它指向的內容回答什麼問題。 | design-principles「原則」 | 原文保留 |
